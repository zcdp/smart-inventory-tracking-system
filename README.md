# Smart Inventory Tracking System

Backend and database design for an RFID-based inventory tracking system.

## Overview

This project was created as a senior design project at Western Michigan University.  
The goal of the system was to support inventory tracking by using RFID tags, readers, locations, and inventory event records.

The system was designed to help track items more accurately and reduce manual inventory work.

## My Role

I worked mainly on the backend and database design side of the project.

My responsibilities included:

- Designing database models for inventory items, RFID tags, readers, locations, and inventory events
- Planning how RFID scan data could be stored and processed
- Supporting documentation and troubleshooting
- Considering data accuracy, duplicate scans, and system reliability

## Main Features

- Item tracking using RFID tag information
- Reader and location-based inventory event records
- Database structure for storing item movement history
- Support for loading, unloading, and inventory movement events
- Documentation for backend and database planning

## Technologies / Concepts

- SQL
- Database design
- Backend system design
- RFID inventory tracking
- Data modeling
- System documentation

## What I Learned

Through this project, I learned how backend and database design can support a real-world inventory tracking system. I also gained experience in organizing data models, planning system logic, and thinking about reliability and accuracy in inventory systems.
